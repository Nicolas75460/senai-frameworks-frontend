# 🚀 Frameworks Front-end

Este repositório reúne todas as atividades, projetos, anotações, resumos e materiais desenvolvidos durante a disciplina de **Frameworks Front-end**.

O objetivo é documentar minha evolução ao longo do semestre, centralizando os conteúdos estudados e servindo como material de consulta para revisões e futuros projetos de desenvolvimento web.

---

# 🎯 Objetivo da Disciplina

A disciplina tem como objetivo desenvolver competências para a criação de aplicações web modernas, utilizando tecnologias e frameworks Front-end amplamente adotados pelo mercado.

Ao longo do semestre serão abordados conceitos fundamentais do desenvolvimento Front-end, desde a configuração do ambiente até a construção, organização e publicação de aplicações utilizando boas práticas de engenharia de software.

# 💡 Competências Desenvolvidas

Ao final da disciplina espera-se desenvolver habilidades para:

- Configurar ambientes de desenvolvimento Front-end;
- Desenvolver interfaces modernas e responsivas;
- Utilizar Git e GitHub no fluxo de desenvolvimento;
- Criar aplicações utilizando Frameworks Front-end;
- Consumir APIs REST;
- Aplicar boas práticas de organização e componentização;
- Publicar aplicações em ambientes de produção.

Além das competências técnicas, também serão desenvolvidas habilidades relacionadas a:

- Trabalho em equipe;
- Organização de projetos;
- Resolução de problemas;
- Pensamento crítico;
- Desenvolvimento de soluções voltadas ao mercado.
