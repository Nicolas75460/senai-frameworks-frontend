# Aula 01 — Apresentação da Disciplina e Contextualização
**Disciplina:** Frameworks Front-end  
**Professor:** Prof. Deivison S. Takatu

---

# Objetivos da Aula

A primeira aula teve como objetivo apresentar a disciplina, sua metodologia, critérios de avaliação, conteúdos que serão estudados ao longo do semestre e contextualizar a importância dos Frameworks Front-end no desenvolvimento de aplicações web modernas.

---

# Contexto da Disciplina

Atualmente, grande parte das aplicações web utiliza frameworks Front-end para criar interfaces modernas, organizadas e de fácil manutenção.

O desenvolvimento Front-end é responsável pela camada visual da aplicação, permitindo que o usuário interaja com o sistema de forma intuitiva. Além da interface, também engloba a experiência do usuário (UX), organização dos componentes e comunicação com o back-end.

A disciplina busca preparar os alunos para desenvolver aplicações profissionais utilizando as tecnologias mais utilizadas pelo mercado.

---

# Introdução ao JavaScript (Vanilla JS)

Antes de iniciar os frameworks, será utilizada a base do desenvolvimento Front-end:

- HTML
- CSS
- JavaScript puro (Vanilla JS)

O JavaScript é a linguagem responsável pela lógica das páginas web, permitindo:

- Manipulação do DOM;
- Comunicação com servidores;
- Criação de interatividade;
- Desenvolvimento de aplicações dinâmicas.

O Vanilla JS representa o JavaScript sem bibliotecas externas, servindo como fundamento para qualquer framework moderno.

# Projeto da Disciplina

O projeto será desenvolvido em grupo e deverá possuir documentação completa, semelhante a um mini TCC, contendo:

- planejamento;
- desenvolvimento;
- funcionalidades implementadas;
- desafios encontrados;
- soluções adotadas;
- benchmarking;
- análise crítica;
- resultados obtidos.

Além da documentação, o projeto será apresentado para avaliação.

---

# Importância do Portfólio

O professor destacou que manter um portfólio durante a disciplina é importante porque:

- demonstra conhecimento técnico;
- comprova experiência prática;
- auxilia na busca por estágios e empregos;
- incentiva a melhoria contínua;
- aproxima o aluno das exigências do mercado.

---

# Atividade da Aula

Em grupos de **3 a 5 integrantes**, os alunos deverão:

1. Criar um repositório no GitHub;
2. Produzir um resumo da Aula 01 em Markdown (`README.md`);
3. Escolher um Framework Front-end;
4. Elaborar um relatório técnico em PDF (mínimo de 5 páginas) contendo:
   - características;
   - vantagens;
   - aplicações no mercado;
   - exemplo de utilização em um projeto web.

---

# Principais Conceitos Aprendidos

- O Front-end é responsável pela interface e experiência do usuário.
- Frameworks Front-end facilitam o desenvolvimento, organização e manutenção de aplicações.
- O JavaScript é a base para o aprendizado dos frameworks.
- Git, GitHub e Deploy fazem parte do fluxo profissional de desenvolvimento.
- O foco da disciplina é desenvolver aplicações reais seguindo boas práticas e metodologias utilizadas no mercado.
